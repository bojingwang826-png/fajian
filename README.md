# 法笺｜法考主观题智能训练与评测平台

> 在线体验：[https://app-fxl3.pocketbay.app](https://app-fxl3.pocketbay.app)

法考主观题背诵 + AI 判分的本地网站。支持 Word/PDF/图片题库识别、导入校对、结构化采分点、默写/填空/弱点速练/模拟考试、逐项 AI 判分、错题汇总和智能复习排期。

## 启动（二选一）

### 方式一：零安装，双击即用（推荐先试这个）

直接**双击打开 `public\index.html`**，浏览器里就能用。

- 数据保存在浏览器 localStorage 中，换浏览器/清缓存前记得在「设置 → 导出备份」
- 无需安装任何东西

### 方式二：本地服务器模式（需安装 Node.js）

1. 安装 Node.js 18 或更新版本（无需 npm install）
2. 双击 `启动.bat`，或在命令行运行：

   ```
   node server.js
   ```

3. 浏览器会自动打开 http://localhost:3737

- 数据保存在 `data/db.json` 文件，自动留备份到 `data/db.backup.json`，比浏览器存储更稳
- 设置里的导出备份不包含 API Key；换电脑恢复备份后需重新填写接口配置。本地 `data/db.json` 仍保存所配置的 Key，请勿分享该文件。
- 换端口：`set PORT=3738 && node server.js`

## ⚡ 一键自动模式（强烈推荐先配置）

在「**设置 → ⚡ AI 自动判分与识别**」里配置一次可用的 OpenAI 兼容 API Key、接口地址和模型，保存并测试连接。模型可用性与费用以服务商当前说明为准。建议用 `node server.js` 启动，本地服务会转发 AI 请求，避免浏览器跨域问题。

DeepSeek 当前预设使用官方 `https://api.deepseek.com/chat/completions` 接口和 `deepseek-flash` 模型。网页端账号与 API 账户分开计费，需要在 `platform.deepseek.com` 创建 API Key 并保证 API 账户有可用余额。

配置之后全站升级为一键操作，不再需要任何复制粘贴：

- **判分**：提交作答 → 点「⚡ 直接判分」→ 网站按固定采分点和分值逐项核对，并自动存档排期。无需复制提示词或粘贴 AI 回复；未配置接口时使用本地结构化判分，已配置时在后台追加语义复核。
- **导入**：选 Word、PDF、图片或题库 JSON → 自动提取题目/答案 → 在校对中心编辑、拆分、合并并检查异常后入库。扫描资料在已配置支持图片的模型时自动 OCR。
- **作答文件**：默写页可上传 `.docx` / `.txt` / `.md`，识别出的作答文字填入编辑框，核对后提交判分。
- **提示**：默写卡住点提示 → AI 直接给出对应级别的提示
- **填空**：一键生成智能挖空题

不配置也能用：所有功能保留「手动复制粘贴」模式作为备选（判分/识别弹窗里可随时切换）。

## 使用流程

1. **题库**：内置 6 道示范题，可直接练习；也可以手动新建，或点「导入题目」上传 `.docx` / `.md` / `.txt`。选择文件后直接显示题目与答案预览；复杂资料可使用站内 AI 识别。
2. **默写模式**：选择题目 → 默写作答 → 提交判分。卡住时点「请求提示」，按 段落主题 → 首2字 → 关键词 三级提示逐级求助，**提示绝不会泄露完整答案**。
3. **填空模式**：可选「AI 智能挖空」（按采分点挖空，约 60%）或「本地快速挖空」（离线近似规则），挖空处直接填词后提交判分。
4. **直接判分**：提交后点击「直接判分」。每项满分来自题库中可编辑的结构化采分点，判分证据必须引用考生作答原文；配置接口后网站在后台进行语义复核并校验结果，不需要打开其他 AI 网站。
5. **判分后自动**：失分采分点进入**错题本**；按得分自动排期复默（≥90→7天后，70-89→3天后，60-69→明天，<60→今天重背），在**仪表盘/复习计划**查看今日待复默。
   新版排期还会结合连续掌握次数和提示使用次数，在 0、1、2、4、7、14、30 天间动态调整。
6. **历史与统计**：得分趋势折线图、各科平均分柱状图、全部判分历史。
7. **模拟考试**：按科目随机组卷并限时作答，交卷后逐题判分并生成总成绩。
8. **设置**：默认宽容度（严格/标准/宽松）、AI 快捷链接、数据导出/导入备份、恢复出厂。

## 判分宽容度

- **严格**：术语和限定词错误一律扣分
- **标准**（默认）：关键法律术语准确即可得分，含义一致不要求一字不差
- **宽松**：含义接近即给分

## 导入文件格式

支持 **.docx（Word）**、PDF、PNG/JPG/WEBP 图片、题库 JSON、.md、.txt 或直接粘贴文本。文字型 PDF 在浏览器本地提取；扫描页和图片需要已配置支持视觉输入的 AI 模型。PDF 组件首次使用时需要联网加载。老版 .doc 请先用 Word/WPS 另存为 .docx。

```text
【科目】刑法
【题目】请默写：正当防卫的成立条件
【标准答案】
一、起因条件：存在现实的不法侵害；
二、时间条件：不法侵害正在进行；
……

------------（多题分隔线）

【科目】民法
【题目】……
【标准答案】
……
```

标准答案建议按采分点分条书写，判分越准确。

除标记格式外，格式化导入还支持「问：… / 答：…」结构（自动识别多题），以及任意普通文本兜底导入（首行为题名、其余为答案）。

## 复杂 Word 资料的 AI 识别

不想整理格式？直接用 AI 识别：

1. 「题库 → 导入题目 → Word / 文本直接导入」，选择 `.docx` 文件；
2. 有明确题目/答案标记的文件直接按标记解析；使用 Word 标题样式及“专题 1 ……”结构的讲义，会按标题层级自动拆题；其余复杂资料在已配置 AI 接口时由网站请求 AI 识别；
3. 核对每道题的题干和标准答案，再点「确认导入」。

AI 会尝试判断科目、拆分多题并整理答案，但法律资料可能包含案例事实、解析、评分标准等混排内容。导入预览会显示原文覆盖率、重复题、答案异常和科目待确认提示，并允许逐题编辑、拆分或合并。老版 `.doc` 仍需另存为 `.docx`。

## 常见问题

- **打不开页面（服务器模式）**：确认 `node server.js` 窗口没有关闭；端口被占用时换端口启动。
- **判分解析失败**：把 AI 回复从头到尾完整复制（包括最后的 JSON 摘要行）；实在不行用手动存档录入总分。
- **提示模式想看答案**：按规则提示模式不输出完整答案，请完成默写后走判分流程查看标准答案。
- **浏览器模式数据会丢吗**：正常使用不会；但清除浏览器缓存/隐私模式会丢，重要数据请定期在「设置 → 导出备份」。
